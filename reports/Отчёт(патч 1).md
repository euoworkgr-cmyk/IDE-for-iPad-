Реализация завершена.

  1. Что реализовано. Локальный запуск активного Python-файла через ▶ Run, Cmd+Enter и Ctrl+Enter; консоль stdout/stderr/traceback;
     input(); virtual FS проекта; повторное использование runtime; изоляция запусков.

  2. Добавлены файлы. Код/Ide для Ipad/src/runtime/PythonRuntime.ts, Код/Ide для Ipad/src/runtime/runPython.ts, Код/Ide для Ipad/src/
     runtime/runPython.test.ts, Код/Ide для Ipad/scripts/copy-pyodide-assets.mjs и четыре файла в public/pyodide/.

  3. Изменены файлы. Код/Ide для Ipad/src/components/App.ts, Код/Ide для Ipad/src/editor/EditorAdapter.ts, Код/Ide для Ipad/src/
     styles.css, Код/Ide для Ipad/vite.config.ts, Код/Ide для Ipad/package.json и package-lock.json. dist/ пересобран.

  4. PythonRuntime. Pyodide 314.0.3 загружается только при первом Run. Runtime настраивает потоки, пересоздаёт каталог проекта, выполняет
     код через compile(..., real_filename, "exec") и возвращает структурированный результат.

  5. Production build. npm run build сначала запускает prepare:pyodide, который копирует core-assets из установленного npm-пакета. Base
     URL вычисляется через document.baseURI, поэтому поддерживается размещение не только в корне домена.

  6. Assets в dist/pyodide.
      - pyodide.asm.wasm — 9 596 462 байта
      - python_stdlib.zip — 2 545 106 байт
      - pyodide.asm.mjs — 1 249 447 байт
      - pyodide-lock.json — 113 804 байта
      - Loader: dist/assets/pyodide-DkmTkHc_.js — около 19,5 КБ

  7. Offline cache. Workbox glob расширен типами mjs, wasm, zip, json. Loader и все четыре runtime-assets фактически найдены в
     сгенерированном sw.js.

  8. Самый большой asset. pyodide.asm.wasm: 9 596 462 байта, примерно 9,15 MiB.
  9. Лимит Workbox. Был не указан — применялось стандартное ограничение 2 MiB. Теперь установлен 11 * 1024 * 1024, то есть 11 MiB:
     достаточно для WASM с небольшим запасом, без чрезмерного увеличения.

  10. stdout/stderr. Используются byte-writers Pyodide и потоковый TextDecoder. Поэтому сохраняются Unicode, переводы строк и
     незавершённый prompt input().

  11. input(). Используется синхронный browser prompt. Python-подсказка появляется в Output, введённая строка возвращается Python. Отмена
     возвращает пустую строку и выводит понятное уведомление.

  12. Virtual FS. Все файлы проекта мапятся в /home/pyodide/altitude-project; вложенные каталоги создаются автоматически. Рабочая
     директория устанавливается в корень проекта, поэтому работают локальные импорты и open("data/config.json").

  13. Изоляция. Каждый запуск получает новый globals-словарь. Модули, загруженные из виртуального проекта, удаляются из sys.modules,
     поэтому изменения utils.py не перекрываются старым module cache.

  14. Ограничения. Pyodide работает в main thread: бесконечный цикл заморозит UI, кнопки Stop пока нет. Дополнительные wheels/pip не
     поставляются. Физическая проверка на iPad остаётся обязательной. Официально текущий Pyodide рекомендует Safari 16.4+ и поддерживает
     локальную Vite-поставку assets: browser support (https://pyodide.org/en/stable/usage/index.html), Vite bundling
     (https://pyodide.org/en/stable/usage/working-with-bundlers.html).

  15. npm run check. Успешно.
  16. npm test. Успешно: 2 test-файла, 10 тестов.
  17. npm run build. Успешно. Vite показывает безвредные предупреждения о условных Node-ветках пакета Pyodide; браузерный запуск проверен.
  18. Production dist. Размер — 17 МБ. npm run preview -- --host 0.0.0.0 запускается, UI с Run и Output открывается. Browser smoke
     подтвердил input(), импорт, stdout, __file__, изоляцию и traceback с main.py.

  19. Service Worker. В precache 20 записей, около 13 963,58 KiB. После прогрева Service Worker локальный сервер был остановлен; новая
     браузерная сессия повторно выполнила Python из offline cache и получила OFFLINE-PYTHON 5. В сетевом журнале первого запуска были
     только локальные запросы. В loader присутствует встроенная fallback-строка CDN самого Pyodide, но Altitude явно переопределяет
     indexURL, packageBaseUrl и cdnUrl локальным URL, поэтому она не используется.
