Импорт файлов из Files.app реализован без изменений PythonRuntime, IndexedDB schema или PWA-архитектуры.

  1. Что реализовано

  В Explorer добавлена компактная кнопка ⇧ с tooltip Import file. После выбора файл:

  - локально читается через File.text();
  - становится обычным ProjectFile;
  - сохраняется в IndexedDB;
  - открывается в CodeMirror;
  - появляется в Explorer и Export ZIP;
  - для .py сразу активируется ▶ Run.

  Отмена picker ничего не изменяет и не считается ошибкой.

  2. Изменённые файлы

  - Код/Ide для Ipad/src/filesystem/importFile.test.ts

  3. iPad Files picker

  Используется скрытый стандартный:

  <input type="file">

  Кнопка Explorer синхронно вызывает input.click(), поэтому Safari показывает системный Files picker. File System Access API, backend и
  upload API не используются.

  4. Поддерживаемые расширения

  Picker ориентирован на:

  - Python: .py
  - C/C++: .c, .cc, .cp, .cpp, .cxx, .h, .hh, .hpp, .hxx
  - C#: .cs
  - JavaScript/TypeScript: .js, .mjs, .cjs, .ts, .mts, .cts
  - Web: .html, .htm, .css
  - Data/text: .json, .xml, .yaml, .yml, .toml, .ini, .txt, .md, .csv
  - неизвестные текстовые файлы — как Plain Text

  5. Определение языка

  Расширен существующий languageFromPath(), второго detector-а нет:

  - .py → Python
  - .c, .h → C
  - .cc, .cp, .cpp, .cxx, C++ headers → C++
  - .cs → C#
  - .js → JavaScript
  - .ts, .mts, .cts → TypeScript
  - неизвестное расширение → Plain Text

  C/C++ пока открываются без специализированной подсветки, а Run остаётся disabled.

  6. Конфликты имён

  Файлы никогда не перезаписываются:

  main.py
  main (1).py
  main (2).py

  Сравнение регистронезависимое и детерминированное.

  7. Ограничение размера и ошибки

  Максимум — 5 MiB на файл. Размер проверяется до file.text(), чтобы крупный файл не попадал в память и CodeMirror.

  Также обрабатываются:

  - ошибка чтения;
  - бинарное содержимое;
  - неправильное имя;
  - ошибка записи IndexedDB;
  - пустой файл — импортируется как допустимый текстовый файл;
  - отмена picker — тихий выход.

  При ошибке текущий проект не мутируется.

  8. IndexedDB и autosave

  Сначала создаётся копия проекта с импортированным файлом, затем она сохраняется через существующий ProjectRepository. UI переключается
  на неё только после успешной записи.

  Последующие изменения импортированного файла проходят через обычный SaveCoordinator и recovery journal.

  9. Export ZIP

  Да. Export ZIP уже проходит по project.files, поэтому импортированные файлы автоматически попадают в архив с сохранением имени и
  содержимого.
