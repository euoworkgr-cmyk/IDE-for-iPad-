  4. Snippet engine

  Trigger определяется как полное слово перед курсором и сопоставляется с текущим LanguageId. Plain Text не получает Python/C# built-ins.
  Пользовательские изменения доступны редактору сразу после сохранения.

  5. Placeholder parser

  Поддерживаются:

  - ${1:text}, ${2:text}…
  - ${0:text} и ${0}
  - числовой порядок
  - повторные ID

  Editor-session построена на штатном CodeMirror snippet(): повторные ${1:i} выделяются одновременно и синхронно редактируются.

  6. Tab priority

  Порядок строго такой:

  1. Выбранный autocomplete.
  2. Следующий placeholder активного snippet.
  3. Trigger текущего языка.
  4. Обычный indent.

  Shift+Tab всегда выполняет outdent. Escape завершает snippet session без удаления текста.

  7. Autocomplete keymap

  Встроенный autocomplete keymap отключён и подключён заново без Enter. Установлен interactionDelay: 0.

  - Tab принимает выбранную подсказку.
  - Enter вставляет новую строку.
  - Клик/тап по autocomplete option остался штатным.

  8. Multiline indentation

  Используется механизм CodeMirror snippet indentation. Каждая следующая строка получает base indentation текущей строки плюс отступ из
  тела snippet.

  9. Хранение

  Создана отдельная IndexedDB:

  - Database: altitude-snippets
  - Version: 1
  - Store: snippets

  Project DB schema не менялась. Snippets глобальны, переживают переключение проектов и полностью работают offline.

  11. Конфликты

  Приоритет:

  user language-specific → user Any → built-in

  Одинаковые language + trigger среди пользовательских snippets запрещены. Built-in можно переопределить через Duplicate. Для копий
  пользовательских snippets создаётся детерминированный trigger -copy, -copy-2 и далее.

  12. Undo

  Перед и после expansion добавлены явные history boundaries. Поэтому:

  cw → Tab → Console.WriteLine(""); → Cmd+Z → cw

  Expansion является отдельным undo-шагом.

  16. Что проверить на iPad

  С Magic Keyboard:

  1. В Python-файле набрать def, нажать Tab.
  2. Ввести имя, Tab, аргументы, Tab, тело.
  3. Сразу после expansion проверить Cmd+Z.
  4. Проверить обычный Tab и Shift+Tab.
  5. В C# набрать cw, нажать Tab.
  6. Открыть autocomplete и принять через Tab.
  7. При открытом autocomplete нажать Enter — должна появиться новая строка.
  8. Создать Debug print / dbg / Python / print(${0:"DEBUG"}).
  9. Проверить dbg + Tab.
  10. Закрыть PWA, включить авиарежим, открыть снова и повторить.
  11. Создать ещё один snippet непосредственно в авиарежиме.
